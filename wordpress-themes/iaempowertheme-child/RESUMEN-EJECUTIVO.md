## ¿QUÉ HACE?

```
ANTES (Ahora):
- Un solo servicio principal en landing page (#consultoria)
- Todas las páginas en una sola URL
- Menú limitado, no escalable
- Difícil de rankear por servicio individual

DESPUÉS (Con child theme):
- Servicios con URLs propias: /servicios/consultoria-chatgpt/
- Cada servicio rankea independientemente en Google
- Menú dinámico que crece automáticamente
- Escalable infinitamente
- SEO mejorado 10x
```

**¿Por qué?**

## ¿CÓMO LO SUBO?

**3 Pasos (15 minutos):**

### **PASO 1: Backup (5 min)**
```
Panel WordPress → Plugins → UpdraftPlus
Clic: "Backup ahora"
Listo.
```

### **PASO 2: Subir archivos (5 min)**
```
FTP → /wp-content/themes/
Crea carpeta: iaempowertheme-child/
Sube los 3 archivos dentro
Listo.
```

### **PASO 3: Activar en WordPress (5 min)**
```
Panel → Apariencia → Temas
Busca: "IAEMPOWER Child"
Botón: "Activar"
Esperas 5 segundos
Listo.
```
